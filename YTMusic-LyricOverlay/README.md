# 🎵 YTMusic Floating Lyrics Overlay

An ultra-clean, always-on-top, synchronized karaoke lyrics overlay for **YouTube Music** (`music.youtube.com`), designed to float seamlessly over your screen and stay visible **across all Windows Virtual Desktops**.

---

## ✨ What's New & Upgraded

- **🇮🇳 Full Hindi & Bollywood Song Support**: Intelligently cleans YouTube video titles (removes `| Movie Name`, `| Actors`, `(From "Film")`, `(Lyrical Video)`, `(Full Song)`, `(Audio Song)`) so Bollywood, Hindi, and Punjabi songs are found immediately.
- **⚡ Always Running with the Music**: Whether a song has millisecond-precise LRC timestamps or plain lyrics from YouTube Music's tab, the extension uses smart pacing so lyrics **always highlight and auto-scroll continuously as playback moves**!
- **👻 Ghost Overlay & Opacity Slider**: Slide background transparency down (from 100% frosted glass all the way to 5% ghost overlay) so lyrics float transparently right over your code editor, games, or desktop wallpaper.
- **✨ Ultra-Clean, Clutter-Free UI**: Clustered buttons are removed. Only pure, glowing lyrics are front-and-center. Hover over or tap **⚙️** to adjust settings.
- **⏳ Auto-Hiding Controls**: Controls fade out automatically after 3 seconds of mouse inactivity, leaving pure floating text on your display.
- **📺 3 Display Modes**:
  - **🪟 Normal**: Resizable, floating Picture-in-Picture window.
  - **📺 Fullscreen Overlay**: Massive cinematic karaoke lyrics across the entire window.
  - **💬 Subtitle HUD**: Compact 1-2 line subtitle ticker.
- **🔍 Manual Song Search**: Open ⚙️ to quickly type any song name or regional title (e.g., *Kesariya*, *Beggin*, *Tum Hi Ho*) to re-query with 1 click.
- **📌 Virtual Desktop Support**: Stays visible across all Windows workspaces.

---

## 🚀 How to Reload the Extension

1. In your browser (Chrome / Edge / Brave), go to:
   - Chrome / Brave: `chrome://extensions`
   - Edge: `edge://extensions`
2. Find **YTMusic Floating Lyrics Overlay**.
3. Click the **🔄 Reload** icon on the extension card.
4. Refresh your YouTube Music tab (`https://music.youtube.com`).

---

## 🎧 How to Use

1. Play any song on [music.youtube.com](https://music.youtube.com).
2. Press <kbd>Alt</kbd> + <kbd>L</kbd> or click the **Mic / Lyrics** icon on the bottom player bar.
3. The clean floating lyrics window will open.
4. Click **⚙️** in the top-right corner to adjust:
   - **Background Transparency** (make it ghost / see-through over your screen)
   - **Text Size**
   - **Display Mode** (Normal / Fullscreen Overlay / Subtitle HUD)
   - **Search / Fix Song Title**

---

## 📌 Keep it Visible Across ALL Virtual Desktops

1. Press <kbd>Win</kbd> + <kbd>Tab</kbd> to open Windows **Task View**.
2. Find the window titled **"YTMusic Floating Lyrics"**.
3. **Right-click** on the window thumbnail.
4. Select **"Show this window on all desktops"**.
